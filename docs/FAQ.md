## Technical Questions

### What are the system requirements?
- **OS:** Linux, macOS, or Windows
- **Python:** 3.9 or higher
- **RAM:** 4GB minimum, 8GB recommended
- **Disk:** 1GB per hour of video
- **FFmpeg:** Required for video rendering

### How long does it take to generate a video?
Depends on duration and hardware:
- 1-minute video: ~2-5 minutes
- 1-hour video: ~15-30 minutes
- 2-hour video: ~30-60 minutes

On GitHub Actions (free tier), expect similar or slightly slower times.

### Can I run this on a Raspberry Pi?
Technically yes, but rendering will be very slow. Better suited for laptops, desktops, or cloud servers.

### Does it work on Windows?
Yes! All Python code is cross-platform. Just make sure to:
- Install FFmpeg and add to PATH
- Use `venv\Scripts\activate` instead of `source venv/bin/activate`
- Use backslashes in paths: `output\video.mp4`

### What video resolution does it generate?
Default is 1280x720 (720p HD). This is optimal for:
- Fast rendering
- Smaller file sizes
- Good quality for ambient content

You can modify settings to generate 1080p or 4K, but it will take longer.

## Content Questions

### What are binaural beats?
Binaural beats are an audio illusion created when two slightly different frequencies are played in each ear. Your brain perceives a third "beat" frequency that can influence brainwave patterns:
- **Delta (0.5-4 Hz):** Deep sleep
- **Theta (4-8 Hz):** Meditation, creativity
- **Alpha (8-13 Hz):** Relaxation, focus
- **Beta (13-30 Hz):** Alert, active thinking
- **Gamma (30-100 Hz):** Peak concentration

### What are Solfeggio frequencies?
Ancient musical frequencies believed to have healing properties:
- **432 Hz:** Natural tuning, harmony
- **528 Hz:** "Love frequency," DNA repair
- **639 Hz:** Connection, relationships
- **741 Hz:** Awakening, expression

### Which mood should I use?
Depends on your target audience:
- **Most Popular:** Sleep, deep focus, study
- **Meditation Niche:** Trance, ceremony, chill
- **Energy/Workout:** Energize, warrior
- **General:** Study, chill, deep focus

Start with "sleep" and "deep_focus" - these have the biggest YouTube audiences.

### Can I customize the visuals?
Yes! Visuals are generated by code in `visuals/`. You can:
- Modify color schemes
- Change fractal patterns (Mandelbrot, Julia)
- Adjust zoom speed and rotation
- Add sacred geometry overlays

### Can I use my own audio?
The engine generates audio algorithmically, but you could modify `audio/` modules to:
- Import custom audio files

See the [YouTube Auth Guide](youtube-auth.md) for detailed setup. Quick version:
1. Create Google Cloud project
2. Enable YouTube Data API v3
3. Get OAuth2 credentials
4. Run `python youtube_upload.py --auth`

GitHub's free CI/CD platform. For public repos, you get unlimited minutes to run automated jobs. Perfect for:
- Scheduled video generation (daily at 2 AM)
- Automatic YouTube uploads
- Batch processing

### How do I set up automation?
1. Fork this repository
2. Add YouTube token to GitHub Secrets

Yes! The included GitHub Actions workflow runs daily at 2 AM UTC. You can change the schedule by editing the cron expression:
```yaml

```

## Troubleshooting

### Video generation fails
Common causes:
1. **FFmpeg not installed:** Install FFmpeg
2. **Missing dependencies:** Run `pip install -r requirements.txt`
3. **Insufficient disk space:** Free up space
4. **Permission errors:** Check folder permissions

### Audio is silent or distorted
Check:
- Sample rate settings (should be 44100 Hz)
- Audio format (WAV recommended for intermediate files)
- Volume levels in audio modules

### Visuals are laggy or glitchy
Try:
- Reduce resolution (720p instead of 1080p)
- Lower framerate (24fps instead of 30fps)
- Increase FFmpeg threads
- Update graphics drivers

### Upload to YouTube fails
Verify:
- OAuth token is valid (re-run `--auth`)
- Video meets YouTube requirements (<128GB, <12 hours)
- Internet connection is stable
- API quotas not exceeded (10,000 units/day default)

### "ModuleNotFoundError"
Ensure virtual environment is activated:
```bash
source venv/bin/activate  # Linux/macOS
venv\Scripts\activate     # Windows
pip install -r requirements.txt
```
